Initial public release of GRC_Claw v1.0 — the open-source Compliance-as-Code platform for agentic AI systems.

Highlights:
- `@grc-claw/sdk`: Compliance-as-Code with `grcfile.yaml`, plan/apply/audit workflow
- `@grc-claw/cli`: `grc init`, `grc scan`, `grc doctor --fix`, `grc diff`, `grc ai-bom generate`
- `@grc-claw/frameworks`: Machine-readable ISO 27001, NIST CSF, SOC 2, ISO 42001 packs
- `@grc-claw/ai-supply-chain`: AI-BOM generator, model provenance, TEE attestation
- `@grc-claw/zk-compliance`: Zero-knowledge proof generation for compliance attestations
- `@grc-claw/agent-identity`: DID:GRC decentralized agent identity + Verifiable Credentials
- `@grc-claw/ingest`: 9-source SIEM/IDS log normalizers (Wazuh, Suricata, Snort, Elastic, UFW + AWS/Azure/GCP)
- `@grc-claw/observability`: OpenTelemetry tracing + AI-BOM generation
- `@grc-claw/compliance-copilot`: PR compliance gates, IDE integration, chat bot
- `@grc-claw/security-graph`: Real-time BFS attack path analysis, blast radius scoring
- `@grc-claw/soar`: DAG playbook engine with 14 response actions + SLA enforcement
- `@grc-claw/compliance-orchestrator`: NeuroSymbolicReasoner with formal proof obligations
