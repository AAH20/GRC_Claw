# Content Marketplace

Agentic AI-powered content marketplace with listing management, pricing optimization, and transaction processing.

## Features

- Content listing management
- Pricing optimization
- Transaction processing
- Trust and safety scoring
- Analytics dashboard

## Installation

```bash
pip install -e .
```

## Usage

```bash
uvicorn content_marketplace.main:app --reload
```

## Testing

```bash
pytest --tb=short -q
```
